# Pokémon Battle Forge — Downloads

A free, fan-made team builder, Pokédex and damage calculator for every generation, with formats for PokeMMO and Radical Red.

## Install

1. Open the [latest release](https://github.com/Venator8696/pokemon-battle-forge-releases/releases/latest).
2. Download `PokemonBattleForge-Setup-<version>.msi` and run it.
3. Windows may show a SmartScreen warning because the installer isn't signed: choose **More info → Run anyway**.

Needs Windows 10 or 11 (64-bit). The app checks this page when it starts and offers new versions itself.
Your teams and formats are saved in `Documents\Pokemon Battle Forge` and stay there across updates and uninstalls.
Before version 1.0.2 the app was called Pokémon Generations Team Builder; updating moves your saves from the old folder to the new one.

This repository only holds the installers.
